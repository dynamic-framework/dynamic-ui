# Hover-prefixed utilities

This project extends Bootstrap utilities to support Tailwind-like `hover:` variants (e.g., `hover:shadow-sm`, `hover:bg-primary-100`, `hover:text-danger`).

## Shadows

<Unstyled>
  <ExampleHoverShadowBoxes />
</Unstyled>

<Source
  code={`
<div class="df-p-4 df-rounded-control df-border-1 df-shadow-none df-hover:shadow-sm">...</div>
<div class="df-p-4 df-rounded-control df-border-1 df-shadow-none df-hover:shadow-md">...</div>
<div class="df-p-4 df-rounded-control df-border-1 df-shadow-none df-hover:shadow-lg">...</div>
<div class="df-p-4 df-rounded-control df-border-1 df-shadow-sm df-hover:shadow-none">...</div>
  `}
  language="html"
/>

## Text color variants

Palette-level variants (e.g., `hover:text-primary-100`, `hover:text-danger-200`) are supported on top of the base `hover:text-*` classes.

<Unstyled>
  <ExampleHoverTextColorVariants />
</Unstyled>

<Source
  code={`
<span class="df-hover:text-primary">hover:text-primary-100</span>
<span class="df-hover:text-primary">hover:text-primary-300</span>
<span class="df-hover:text-primary">hover:text-primary-700</span>
<span class="df-hover:text-danger">hover:text-danger-200</span>
<span class="df-hover:text-success">hover:text-success-400</span>
<span class="df-hover:text-warning">hover:text-warning-500</span>
  `}
  language="html"
/>

## Border color variants

Palette-level variants (e.g., `hover:border-primary-100`, `hover:border-danger-200`) are supported by combining the `hover:` prefix with any palette shade available in the design system.

<Unstyled>
  <ExampleHoverBorderColorVariants />
</Unstyled>

<Source
  code={`

<div class="df-border-1 df-border-2 df-hover:border-primary">...</div>
<div class="df-border-1 df-border-2 df-hover:border-danger">...</div>
<div class="df-border-1 df-border-2 df-hover:border-success">...</div>
  `}
  language="html"
/>
