# Dark-prefixed utilities

This project extends Bootstrap utilities to support Tailwind-like `dark:` variants (e.g., `dark:bg-primary-100`, `dark:text-success`, `dark:shadow`).

Dark variants are applied automatically when the user's system prefers a dark color scheme (`prefers-color-scheme: dark`), and can also be opted into by putting `data-df-theme="dark"` on any ancestor element. It is an attribute rather than a class so a theme can be set on a subtree — a dark panel on a light page — and not only on the document root.

> Tip: Without `data-df-theme`, these utilities will also activate automatically when the browser/OS switches to night mode via `prefers-color-scheme: dark`.

## Customizing Bootstrap button CSS variables in dark mode

You can override component CSS variables in a plain CSS/SCSS file to tailor dark mode. Use either the automatic system preference or the `data-df-theme="dark"` opt-in:

<Source
  code={`
/* System dark mode */
@media (prefers-color-scheme: dark) {
  .btn-primary {
    /* Base and text */
    --df-button-bg: var(--df-role-primary-base-hover);
    --df-button-fg: var(--df-bg-canvas);
    --df-button-border-color: var(--df-role-primary-base-hover);

    /* Hover */
    --df-button-hover-bg: var(--df-role-primary-base-hover);
    --df-button-hover-border-color: var(--df-role-primary-base-hover);

    /* Focus — the ring is shared across components in 3.x, so a button does
       not carry its own. Restyle it once and every control follows. */

    /* Active */
    --df-button-active-bg: var(--df-role-primary-base-active);
    --df-button-active-border-color: var(--df-role-primary-base-active);
  }

  .df-button[data-variant="outline"][data-color="secondary"] {
    --df-button-fg: var(--df-role-secondary-base);
    --df-button-border-color: var(--df-role-secondary-base);
    --df-button-hover-bg: color-mix(in oklab, var(--df-role-secondary-base) 12%, transparent);
    --df-button-hover-border-color: var(--df-role-secondary-base);
  }
}

/* Opt-in dark container */
[data-df-theme="dark"] {
  .btn-primary {
    --df-button-bg: var(--df-role-primary-base-hover);
    --df-button-fg: var(--df-bg-canvas);
    --df-button-border-color: var(--df-role-primary-base-hover);
    --df-button-hover-bg: var(--df-role-primary-base-hover);
    --df-button-hover-border-color: var(--df-role-primary-base-hover);
    --df-button-active-bg: var(--df-role-primary-base-active);
    --df-button-active-border-color: var(--df-role-primary-base-active);
  }
}
  `}
  language="css"
/>
