# Design Tokens

Dynamic Framework builds on Bootstrap 5 and exposes a robust set of CSS variables and Sass tokens to craft brand themes. Prefer overriding CSS variables at runtime for theming, and use Sass variables for build-time defaults when shipping a custom bundle. Official documentation is available at https://docs.modyo.com.

<br />

## Principles
- Scope overrides: use `:root` for global themes, `[data-df-theme="brand"]` or `body.brand` for app-specific, and `[data-df-theme="dark"]` or `prefers-color-scheme` for dark mode.
- Change variables, not classes: utilities and components read from CSS variables; overriding variables updates the whole system consistently.
- Validate contrast: ensure WCAG AA for text/background, borders, and focus rings.

<br />

### Core variables (what to override)
These variables drive components and utilities; override them to theme typography, colors, spacing, borders, shadows, and dark mode consistently.

#### Typography
Key CSS variables:
- Family and body: `--df-font-family-sans`, `--df-font-size-300`, `--df-line-height-normal`
- Heading sizes: `--df-text-heading-1-font-size` … `--df-text-heading-6-font-size`
- Display sizes: `--df-text-display-1-font-size` … `--df-text-display-6-font-size`
- Small text: `--df-font-size-200`; line-heights: `--df-line-height-snug`, `--df-line-height-normal`, `--df-line-height-loose`
- Heading line-height: `--df-line-height-tight`

Example:
```css
:root {
  --df-font-family-sans: "Jost", system-ui, sans-serif; /* or your brand font */
  --df-font-size-300: 1rem; /* base body size */
  --df-text-heading-1-font-size: 3rem; /* h1 */
  --df-text-heading-2-font-size: 2.5rem;
  --df-text-heading-3-font-size: 2rem;
  --df-text-heading-4-font-size: 1.5rem;
  --df-text-heading-5-font-size: 1.25rem;
  --df-text-heading-6-font-size: 1rem;
  --df-font-size-200: .875rem; /* small text */
}
```

#### Color system
Dynamic’s palettes expose base tokens and extended shades.
- Base semantic tokens: `--df-role-primary-base`, `--df-role-success-base`, `--df-role-warning-base`, `--df-role-danger-base`, `--df-role-info-base`, `--df-role-secondary-base`, `--df-bg-muted`, `--df-bg-inverse`
- Extended shades by state: e.g., `--df-role-primary-subtle`, `--df-role-primary-subtle`, …, `--df-role-primary-base-active`
- Text/background/border subtles: `--bs/{token}-text-emphasis`, `--bs/{token}-bg-subtle`, `--bs/{token}-border-subtle`
- Body defaults: `--df-fg-default`, `--df-bg-canvas`, links: `--df-fg-link`, `--df-fg-link-hover`

Override with either RGB bases or direct colors:
```css
:root {
  /* Brand primaries */
  --df-role-primary-base: #0b74ff;
  --df-role-primary-subtle: #e5f0ff; /* light tint */
  --df-role-success-base: #0c8a50;
  --df-role-warning-base: #d99100;
  --df-role-danger-base: #c83333;
  --df-role-info-base: #0aa0c8;
  --df-role-secondary-base: #5b6670;

  /* Body and links */
  --df-fg-default: #2e3438;
  --df-bg-canvas: #ffffff;
  --df-fg-link: #0b74ff;
  --df-fg-link-hover: #095fd1;
}
```

### Spacing scale
Override spacing globally or create theme scopes:
```css
:root {
  --df-size-4: 16px;  /* baseline */
  --df-size-6: 24px;
  --df-size-8: 32px;
  --df-size-12: 48px;
}
[data-bs-theme="compact"] {
  --df-size-6: 20px; /* tighter */
}
```

#### Borders, radius, shadows, focus
- Radius: `--df-shape-control`, `--df-shape-control-sm`, `--df-shape-control-lg`, `--df-shape-surface`, `--df-shape-surface-lg`, `--df-shape-pill`
- Border: `--df-stroke-control`, `--df-stroke-divider`, `--df-border-default`, `--df-border-muted`
- Shadows: `--df-elevation-md`, `--df-elevation-sm`, `--df-elevation-lg`
- Focus ring: `--df-focus-ring-width`, `--df-focus-ring-offset`, `--df-focus-ring`

```css
:root {
  --df-shape-control: .5rem;
  --df-shape-control-lg: .75rem;
  --df-elevation-md: 0 2px 8px rgba(0,0,0,.08);
  --df-focus-ring-width: 2px;

  --df-role-primary-base: #0b74ff;
}
```

## Component tokens (examples)
Many component styles are derived from the core variables, but some expose specific tokens:
- Buttons: variant tokens are generated off theme colors; customize via core color variables and (optionally) component CSS vars like --df-button-radius
- Alerts/Badges: read semantic tokens and bg-subtle/border-subtle
- Forms: validation colors map to --df-role-success-base/border-color, --df-role-danger-base/border-color

```css
/* Optional per-component tweak */
:root {
  --df-button-radius: var(--df-shape-control-lg);
}
```

<br />

## Dark mode patterns
- Use dark: utilities for class-based overrides and @media prefers-color-scheme for system dark.
- Define token pairs for light/dark to ensure consistent tints and emphasis colors.

```css
.dark {
  --df-bg-muted: #1b2129;
  --df-fg-muted: rgba(230,230,230,.75);
  --df-role-danger-subtle: #471c1c; /* dark tint variant */
}
```

<br />

## Theming workflow (recommended)
1. Define brand color palette (primary/success/warning/danger/info/secondary + tints 25–900).
2. Set typography: body family/size, heading/display scales, small text, line-heights.
3. Tune spacing scale and component gaps using `--df-size-*`.
4. Adjust radius, borders, shadows, focus tokens for personality and accessibility.
5. Implement dark mode via prefers-color-scheme and `[data-df-theme="dark"]`, validate contrast.
6. Verify utilities (fs-*, display-*, text-*, bg-*, border-*) reflect your overrides.

## Bootstrapping a theme (copy-paste starter)
```css
/* Global theme */
:root {
  /* Typography */
  --df-font-family-sans: "Jost", system-ui, sans-serif;
  --df-font-size-300: 1rem;
  --df-line-height-tight: 1.2;
  --df-font-size-200: .875rem;

  /* Color tokens */
  --df-bg-canvas: #ffffff;
  --df-fg-default: #2e3438;
  --df-role-primary-base: #0b74ff;
  --df-role-success-base: #0c8a50;
  --df-role-warning-base: #d99100;
  --df-role-danger-base: #c83333;
  --df-role-info-base: #0aa0c8;
  --df-role-secondary-base: #5b6670;

  /* Spacing */
  --df-size-4: 16px;
  --df-size-6: 24px;

  /* Radius/Shadows */
  --df-shape-control: .5rem;
  --df-elevation-md: 0 2px 8px rgba(0,0,0,.08);
}

/* System dark support */
@media (prefers-color-scheme: dark) {
  :root {
    --df-bg-canvas: #0e1116;
    --df-fg-default: #e6e6e6;
    --df-border-default: #2a2f36;
  }
}
```
