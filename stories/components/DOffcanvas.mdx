# Offcanvas

This section provides guidance specifically for using `DOffcanvas` in **inline** scenarios.

<Unstyled>
  <DAlert color="warning">
    <span>
      To achieve the behavior of a offcanvas it is necessary to use the

      [Offcanvas Usage](/docs/design-system-components-offcanvas-usage--docs)
      in our documentation.
    </span>
  </DAlert>

## Import

Import it from the `overlay` subpath. It is the only entry point that depends on
`framer-motion`, so a widget that does not use it does not bundle the library.
The root import still works but is deprecated and will be removed in 3.0.

<Source
  code={`import { DOffcanvas } from '@dynamic-framework/ui-react/overlay';`}
  language="tsx"
  dark
/>
