# Modal

This section provides guidance specifically for using `DModal` in **inline** scenarios.

<Unstyled>
  <DAlert color="warning">
    <span>
      To achieve the behavior of a modal it is necessary to use the

      Usage](/docs/design-system-components-modal-usage--docs) page in our
      documentation.
    </span>
  </DAlert>

## Import

Import it from the `overlay` subpath. It is the only entry point that depends on
`framer-motion`, so a widget that does not use it does not bundle the library.
The root import still works but is deprecated and will be removed in 3.0.

<Source
  code={`import { DModal } from '@dynamic-framework/ui-react/overlay';`}
  language="tsx"
  dark
/>
